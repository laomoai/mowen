# 墨问 v2.5.2：累计余额图表顺序修复

## 问题

原始数据图表默认按横轴标签排序。资金表横轴选择“项目”、纵轴选择“余额”时，记录会按项目名称重新排列，导致正确的累计余额在折线图中显示为错误的时间走势。

## 修复

- 当原始模式的任一 Y 轴字段为累计余额时，图表记录严格按该字段的 `order_field` 和 `order_direction` 排列。
- 横轴仍负责显示项目、日期等标签，但不再覆盖累计余额的计算顺序。
- 普通数值图表不受影响，仍按原有横轴标签规则排序。
- ID 正序资金表的预期走势为：`2000 → 4000 → 3860 → 3560 → 3475 → 3437`。

## 验收

- 自动测试覆盖 ID 正序、ID 倒序以及普通图表排序不回归。
- 生产验收需确认资金表折线图从 ID 1 到 ID 6 依次绘制，并保持表格页面 ID 倒序展示。

## 回滚

此变更只影响前端图表点位排序，不修改数据库、字段配置或业务记录。回滚到上一 release 并重启服务即可。
